This directory contains files that were used to generate low-resolution images in built-in vcmi mod

Multiplier in name indicates upscaling factor compared to original H3 resolution.

All upscaled images in vcmi mod were generated by downscaling images from this directory to x1..x4 factor 

List of images:
- queueDefend-x12 - based on VCMI icon, with sepia effect applied and logo removed
- stackWindowIcons-x10 - based on https://opengameart.org/content/powers-icons
- vcmi-x12 - based on VCMI icon, with logo removed
- gear-x12 - made from scratch
